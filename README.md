# Constellation

A Rust crate allowing the manipulation of satellite constellations following Walker patterns.

## Features

- Build a Constellation structure from a [Constellation Code](https://datatracker.ietf.org/doc/draft-piraux-space-constellation-code/).
- Simulate the dynamics of the constellation through time.
- Determine the satellites in the sight cone of a ground station, as well as the distance and latency of such potential feeder links.
